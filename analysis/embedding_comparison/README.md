# Embedding comparison: SubCell embeddings of real vs ProtiCelli-simulated images

Per-protein SubCell embeddings of real HPA images and of ProtiCelli-simulated images, twelve
cell lines: the joint UMAP grids with real-vs-simulated separation and location purity (Fig 3A,
Fig S5A) and the k-NN subcellular-location label transfer with a morphology-only baseline (Fig 3B).

## Run

```bash
PY=/path/to/python bash run_embedding_comparison.sh        # every step, in order
STEPS=plot bash run_embedding_comparison.sh                # only re-plot from data/
```

Steps, in order: `arms` (12 cell lines x 3 sampling seeds) -> `umaps` (one joint fit per cell
line) -> `transfer` (12 cell lines x 3 seeds) -> `plot`. The three compute steps are independent per cell line and
written as loops; split them across a cluster as you like.

| script | role |
|---|---|
| `utils/build_arms.py` | the per-protein mean embeddings: real means over the HPA cells selected with the SubCell paper's cell filters (location annotated, single-gene antibody, reliability not Uncertain, one best antibody per gene), and simulated means over the same number of cells per protein; one npz per (cell line, seed) in `ARMS_DIR` |
| `umaps/fit_umaps.py`, `umaps/plot_panel_A.py` | joint UMAP per cell line, 15-NN statistics in 1,536-D, Procrustes-aligned grids |
| `label_transfer/score_transfer.py`, `label_transfer/plot_panel_B.py` | k = 5 cosine label transfer from the real images' embeddings, queried with real, simulated and morphology-only embeddings |

## Inputs

| input | env | used by |
|---|---|---|
| SubCell embeddings of the HPA single-cell images, one h5ad (obs atlas_name, antibody, ensembl_ids, gene_names, locations, gene_reliability, reliability_rank; X = 1,536-D) | `INPUT_H5AD` | `arms` |
| SubCell embeddings of the ProtiCelli-simulated images, one h5 shard set per cell line (`<line>/*.h5`: obs/gene_name, X) | `NORM_V2` | `arms` |
| the HPA subcellular location annotation per gene and cell line, pickled as `{gene: {atlas_name: [locations]}}` (proteinatlas.org, "Subcellular location data") | `NORM_V2/annotations/location_map.pkl` | Fig 3A colouring, Fig 3B labels |
| the morphology-only baseline: the same real cells re-embedded with the protein channel blanked and averaged per protein like the real images, one npz per cell line (genes, morph) | `MORPH_DIR` | Fig 3B |
| where the per-protein mean embeddings are written and read | `ARMS_DIR` | all steps |

Both embedding files are generated by running the single-cell images through SubCell
([SubCellPortable](https://github.com/CellProfiling/SubCellPortable)): the HPA single-cell crops
and the ProtiCelli-simulated images, which will be available from the HPA website upon
publication. The HPA single-cell crops are segmented from the HPA subcellular images (ProtiCelli used HPA v24,
https://v24.proteinatlas.org/) as described in the Methods. A processed version of the v23 data,
segmented crops with their SubCell embeddings, can be downloaded for testing from
https://virtualcellmodels.cziscience.com/dataset/hpa-subcellular-section-subcell and should yield
similar results.

## Outputs

| figure | script | files |
|---|---|---|
| Fig 3A, Fig S5A, joint UMAP grids (the six cell lines with the most proteins, the six with the fewest) | `umaps/plot_panel_A.py` | `umaps/figures/F_panelA_{main6,supp6}.*`, `umaps/data/panelA_stats.csv` |
| Fig 3B, label transfer | `label_transfer/plot_panel_B.py` | `label_transfer/figures/F_label_transfer.*`, `label_transfer/data/lt_{allseeds,per_line,by_arm}.csv` |

The separation and purity quoted in the text come from `panelA_stats.csv`, the label-transfer
means from `lt_by_arm.csv`. The compute steps write the per-protein means to `ARMS_DIR` and one
part per cell line into `umaps/data/panelA_parts/` and `label_transfer/data/panelB_parts/`. `data/` and `figures/`
are not tracked.

## Environment

Python >= 3.10 with `requirements.txt` (the plot scripts need only its first block).
