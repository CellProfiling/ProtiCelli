# Hierarchical Leiden trees

Multi-level Leiden subclustering of SubCell embeddings, U2OS: the hierarchy tree of the
simulated images with GO labels (Fig 3C), the subcluster UMAPs and the real-vs-simulated AMI
across hierarchy levels with its real-vs-real split-half ceiling (Fig 3D), the hierarchical map
of one simulated cell with co-clustering scores and co-occupancy heatmaps (Fig 6B) and the
validation of the co-clustering score against real single-cell spread (Fig S10).

## Run

```bash
PY=/path/to/python bash run_hierarchical_tree_analysis.sh        # every step, in order
STEPS=plot bash run_hierarchical_tree_analysis.sh                # only re-plot from data/
```

Steps, in order: `consensus` -> `cell_tree` -> `tree_caches` -> `halves` -> `ceiling` (30 runs)
-> `ladder` (30 runs) -> `pick` -> `enrich` -> `panel_d_umap` -> `validation` -> `plot`. The
`ceiling`, `ladder` and `consensus` steps are the heavy ones.

| script | role |
|---|---|
| `utils/hier.py` | the 7-level Leiden subclustering (targets 1, 2, 6, 14, 22, 38, 86 clusters) with the maximum-modularity resolution tuner |
| `utils/treelib.py` | label IO, hierarchy builder, graphviz layout, left-to-right renumbering, the two tree renderers, the 2x2 subcluster UMAPs |
| `utils/arms.py` | reads the per-protein mean embeddings (real and simulated) that the embedding comparison writes, and selects the HPA cells for the split halves with the SubCell paper's cell filters (copies of the functions in `embedding_comparison/utils/build_arms.py`) |
| `tree_comparison/panelCD_cluster.py`, `plot_panels_C_D.py` | split halves, the real-vs-simulated and real-vs-real clustering runs, the run drawn in Fig 3C and 3D, GO labels, UMAPs |
| `tree_consensus/consensus_leiden.py`, `cell_tree.py`, `build_tree_caches.py`, `plot_tree_heatmaps.py` | co-clustering matrices across cells, the single-cell tree, co-clustering scores + co-occupancy heatmaps; Fig 6B |
| `cluster_validation/cluster_validation.py`, `plot_fig_S10.py` | real single-cell spread per tree node; Fig S10 |

## Inputs

| input | env | used by |
|---|---|---|
| the per-protein mean embeddings, real and simulated, written by the embedding comparison's `arms` step (U2OS, 3 sampling seeds) | `ARMS_DIR` | `halves`, `ladder`, `panel_d_umap` |
| SubCell embeddings of the HPA single-cell images, one h5ad (see `embedding_comparison/README.md`) | `INPUT_H5AD` | `halves` |
| where the split halves are written and read | `HALVES_DIR` | `halves`, `ceiling` |
| SubCell embeddings of every ProtiCelli-simulated U2OS cell, one h5ad (obs cell_id, gene_name; X = 1,536-D; 200 cells x 12,800 proteins) | `EMBEDDINGS` | `consensus`, `cell_tree` |
| where the consensus matrices are written and read | `CONSENSUS_DIR` | `consensus`, `tree_caches` |
| the reference cell (default 134), its simulated image array (512 x 512 x 12,800 uint8) and protein order | `CELL_ID`, `STACK`, `PROTEIN_ORDER` | `tree_caches` |
| the SubCell per-cell embeddings of the real HPA images, a torch .pth holding (metadata DataFrame with atlas_name and gene_names, embedding tensor) | `HPA_REAL_FEATURES` | `validation` |
| where the validation intermediates go | `VALIDATION_CACHE` | `validation` |

The embedding files are generated by running the single-cell images through SubCell
([SubCellPortable](https://github.com/CellProfiling/SubCellPortable)), the HPA single-cell crops
and the ProtiCelli-simulated images alike. The simulated images will be available from the HPA
website upon publication. The HPA single-cell crops are segmented from the HPA subcellular images (ProtiCelli used HPA v24,
https://v24.proteinatlas.org/) as described in the Methods. A processed version of the v23 data,
segmented crops with their SubCell embeddings, can be downloaded for testing from
https://virtualcellmodels.cziscience.com/dataset/hpa-subcellular-section-subcell and should yield
similar results.

| figure | script | files |
|---|---|---|
| Fig 3C, hierarchy tree of the simulated images | `tree_comparison/plot_panels_C_D.py` §1 | `tree_comparison/figures/F_tree_generated.*`, `F_tree.pick.json` |
| Fig 3D, subcluster UMAPs (levels 2-4) and AMI across levels | same, §2-3 | `F_panelD_level{2,3,4}.*`, `F_ladder.*` + `.source.csv` |
| Fig 6B, hierarchical map of the reference cell | `tree_consensus/plot_tree_heatmaps.py` | `tree_consensus/figures/F_consensus_tree.*` |
| Fig S10, co-clustering score vs real spread | `cluster_validation/plot_fig_S10.py` | `cluster_validation/figures/F_fig_S10.*` |

The per-level AMI and the observed / ceiling fraction quoted in the text are in
`tree_comparison/data/published_ladder_with_ceiling.csv`. The compute steps write
`tree_comparison/data/{ceiling,ladders,labels,enrichment,umap_cache}/`,
`tree_consensus/data/cell_<id>/` (labels, co-clustering scores, heatmaps) and
`cluster_validation/data/node_master.parquet`.

## Environment

Python >= 3.10 with `requirements.txt` (the plot scripts need only its first block) and the
graphviz `dot` binary, which `treelib` looks for next to the interpreter.
